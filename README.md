**现有功能：**
1. 知识库。可以管理文献及文件，支持pdf、md、docx、txt、LaTex项目。
2. 阅读与笔记。可以阅读文献pdf及文件，并且支持做笔记，笔记支持md格式。
3. 写作。支持md和LaTex格式的写作。
4. ARXIV快递。按照所关注的领域，设定好之后每天可收到新增文献报告。
5. 求知域。以MindMap形式与AI对话，更加条理清晰。
6. AI助手。伴随式AI助手，可随时与AI对话讨论文献，并可帮助完成文献导入、文献分类整理等几乎所有的软件功能，使得软件使用更加高效。

注：当前版本支持Windows。
